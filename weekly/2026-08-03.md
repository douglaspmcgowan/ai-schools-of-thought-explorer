## Techniques & tricks

**Output structure upfront cuts post-processing 60–80%** (https://getprompting.com/prompt-engineering-guide/): Specifying exact output format (JSON, markdown table, numbered list) in your prompt reduces downstream pipeline cleanup by 60–80% in production workflows — specify the structure before the task, not after.

**"Reason through this before answering" → 40% accuracy gain** (https://getprompting.com/prompt-engineering-guide/): Appending an explicit reasoning instruction to complex prompts improves LLM accuracy on multi-step logic tasks by up to 40% — works across models and tasks with no other changes.

**Subagent model routing for coding tasks** (https://simonwillison.net/2026/Jul/3/): Simon Willison's technique: instruct a coding agent to choose a lower-power model (Haiku for trivial edits, Sonnet for implementation) and spawn a subagent to run the task, reviewing the result in the main loop before committing — cheaper and faster while keeping quality.

**UV_EXCLUDE_NEWER for reproducible uvx in GitHub Actions** (https://simonwillison.net/2026/Jul/14/): Set UV_EXCLUDE_NEWER=<date> in your workflow env and use it as a cache key so uvx resolves tools to their state as of that date — bump the date to upgrade and bust the cache automatically.

**LLM knowledge bases: structured wikis instead of raw document context** (https://karpathy.bearblog.dev/sequoia-ascent-2026/): Karpathy's technique of building interlinked markdown wikis compiled by an LLM from source documents, then querying specific chapters on-demand rather than injecting entire books into context — shifts token spend from repetition to retrieval.
